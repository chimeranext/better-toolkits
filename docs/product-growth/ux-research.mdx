# UX Research

The UX research toolkit guides you through creating professional UX research
artifacts through structured dialogue. It produces structured JSON data and
interactive HTML visualizations for maps and user research.

This is a **playbook**: it explains *when and why* to use each skill. For the
executable steps, open the skill itself (the runbook).

## When to use this toolkit

Use the UX research toolkit when the work is understanding users:

- You must map the user experience or a day in their life.
- You must map a specific journey with an existing product.
- You must map internal service processes behind a journey.
- You must plan agile work with user stories.

It is the default toolkit for turning user understanding into visual artifacts.

## Core skills — when and why

| Skill | When to use it | Why |
| --- | --- | --- |
| **map-workshop** | you are starting from zero | it guides you through the whole map creation process |
| **experience-map** | the user has no product yet | it maps a general day in the life |
| **customer-journey-map** | the product exists | it maps the experience with the specific product |
| **service-blueprint** | you need internal processes | it maps frontstage and backstage behind the journey |
| **storyboard** | you need a visual narrative | it tells the user story in emotional scenes |
| **user-story-map** | you need agile planning | it breaks the journey into development stories |
| **design-studio** | you must explore design solutions | it runs a structured collaborative sketch exercise |
| **fidelity-guide** | you must know what to expect from testing | it matches artifacts to the feedback you can trust |
| **research-cadence** | you need continuous discovery | it sets a repeatable weekly testing rhythm |
| **session-replay** | you must see real user behavior | it uses recorded sessions with privacy masking |

## When NOT to use this toolkit

- For validating the business model — use the business model toolkit.
- For running paid acquisition — use the revenue growth toolkit.
- For course authoring — use the instructional design toolkit.
- A single quick question does not need a full research artifact.
