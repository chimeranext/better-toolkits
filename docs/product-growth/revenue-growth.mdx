# Revenue Growth

The revenue growth toolkit executes the AAARRR framework (Awareness,
Acquisition, Activation, Revenue, Retention, Referral) across paid media
channels. It combines a strategic funnel and flywheel view with campaign
execution and safety guardrails.

This is a **playbook**: it explains *when and why* to use each skill. For the
executable steps, open the skill itself (the runbook).

## When to use this toolkit

Use the revenue growth toolkit when the work is revenue and growth execution:

- You must plan and run paid acquisition campaigns.
- You must analyze and optimize funnel performance.
- You must control budget and decide which campaigns to kill.
- You must measure revenue, LTV, CAC, and retention.

It is the default toolkit for driving measurable revenue from paid channels.

## Core skills — when and why

| Skill | When to use it | Why |
| --- | --- | --- |
| **revenue-strategy** | you must set high-level revenue direction | it sets objective, channel mix, budget split, and lifecycle decisions |
| **media-plan** | you have an objective and need a campaign plan | it turns the objective into a draft media plan per network |
| **landing-instrumentation** | a landing needs tracking installed | it wires the full attribution stack (pixel, CAPI, analytics) |
| **landing-page-design** | you need a high-conversion landing | it guides conversion-focused landing page design |
| **meta-graph-api** | you call the Meta Marketing API directly | it documents endpoints, errors, and retry patterns |
| **creative-testing** | you must test and iterate ad creatives | it launches creative tests and pauses losers with readouts |
| **budget-pacing** | you must watch delivery versus budget | it flags underdelivery and overspend without auto-executing |
| **attribution-readout** | you must report lift across channels | it merges multi-network insights into one unified row |
| **kill-rules** | you must decide what to pause or kill | it encodes hard thresholds (CPA, ROAS, LTV:CAC) and proposes kills |
| **pricing-strategist** | you must set or revise pricing | it picks a model, validates willingness-to-pay, and designs packaging |
| **revenue-ops** | you must analyze the sales pipeline | it reviews coverage, velocity, and forecast accuracy |
| **revenue-ops-triage** | you have a messy pipeline or backlog | it turns analyzer outputs into ordered, agent-ready work |
| **b2g** | you sell to governments | it gives a tender and public-private partnership playbook |
| **social-publishing** | you post organic social content | it publishes across platforms with media upload |

## When NOT to use this toolkit

- For validating the business model or building a pitch — use the business model toolkit.
- For shipping an app to stores — use the app go-to-market release toolkit.
- For very early problem validation — use the business model toolkit first.
- A single quick question does not need the full campaign system.
