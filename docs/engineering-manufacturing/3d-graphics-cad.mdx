# 3D Graphics & CAD

The 3D Graphics & CAD toolkit covers modeling, simulation, visualization, and
digital-twin work across engineering, design, and interactive 3D. Use it when
you create, transform, or render 3D content, or build CAD and digital-twin
pipelines.

This is a **playbook**: it explains *when and why* to use each skill. For the
executable steps, open the skill itself (the runbook).

## When to use this toolkit

Use 3D Graphics & CAD when the work involves 3D content:

- You model parts, assemblies, or scenes in CAD tools.
- You simulate structural, fluid, or dynamic behavior.
- You prepare toolpaths for machining or slicing for additive.
- You import, export, convert, or validate 3D models.
- You work with building models, digital twins, or VR/AR.
- You program 3D rendering or desktop GUIs in Rust.
- You produce animation or visual effects.

## Core skills — when and why

| Skill | When to use it | Why |
| --- | --- | --- |
| **cad** | you create engineering CAD models | it gives parametric modeling, drafting, and collaboration guidance across major tools |
| **cae** | you simulate and validate a product | it covers finite element analysis, computational fluid dynamics, and multi-body dynamics |
| **cam** | you prepare parts for fabrication | it covers CNC toolpaths and slicing for additive manufacturing |
| **model-operations-3d** | you import, export, convert, or validate 3D models | it covers the core STL, OBJ, GLB/glTF, and USD operations |
| **bim** | you work on building models and openBIM exchange | it covers Revit, ArchiCAD, BlenderBIM, and IFC workflows |
| **graphics-cad-3d-toolkit** | you need multi-tool 3D, CAD, or digital-twin guidance | it consolidates AutoCAD, Rhino, Blender, Maya, and Omniverse workflows |
| **gemelos-digitales** | you build digital twins | it covers OpenFactory, OpenTwin, rv-ODT, ThingWorx, Azure Digital Twins, and Omniverse |
| **rv-otd-schema-management** | you author, map, or version twin data schemas | it applies the Open Digital Twin Format (rv-ODT) standard |
| **bevy-iced-integration** | you build a Rust desktop app with a 3D scene and GUI | it combines Bevy rendering with the Iced UI framework |
| **vr-ar** | you build virtual or augmented reality | it covers XR interaction design, 3D optimization, and real-time rendering |
| **videojuegos** | you build interactive entertainment or serious games | it spans game design, code, art, and QA across engines |
| **vfx** | you produce film, advertising, or real-time VFX | it covers particles, simulation, and compositing |
| **animacion-digital** | you animate 2D or 3D content | it covers keyframing, rigging, and cinematic rendering across tools |

## When NOT to use this toolkit

- For choosing a physical manufacturing process, DFM, or tolerances — use the Manufacturing & Robotics toolkit.
- For electrical or PCB design — use the Schematics & PCB toolkit.
- For supply chain or importing — use the Logistics toolkit.
- For software engineering process — use the corresponding engineering toolkit.
