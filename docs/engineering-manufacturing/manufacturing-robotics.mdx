# Manufacturing & Robotics

The Manufacturing & Robotics toolkit covers the physical production side of
hardware and products: choosing how to make a part, designing it so it can be
made, handing it to a machine shop, and running lean quality systems on the
floor. Use it when you plan, design, verify, or operate manufacturing and
robotics work.

This is a **playbook**: it explains *when and why* to use each skill. For the
executable steps, open the skill itself (the runbook).

## When to use this toolkit

Use Manufacturing & Robotics when the work touches physical production:

- You decide how to make a part (print, mold, machine, or cast).
- You design or review a part so it can be manufactured.
- You hand a design to a machine shop or CAM.
- You specify tolerances, fits, or material properties.
- You run a production floor under lean or quality principles.
- You must verify a manufacturing or robotics process behaves as specified.

## Core skills — when and why

| Skill | When to use it | Why |
| --- | --- | --- |
| **additive-manufacturing** | you choose between FDM, SLA/DLP, and SLS/MJF | it matches the process to part size, tolerance, surface finish, material, and run size |
| **cad-cam-handoff** | you hand a design to a machine shop or CAM | it picks the right export format (STEP/IGES vs native), mesh settings, drawing standards, and quote package |
| **dfm** | you review a part for manufacturability | it enforces rules (wall thickness, drafts, tool radius) that prevent costly rework |
| **modeling-3d** | you create or structure a parametric 3D model | it keeps parts vs assemblies, sketches, constraints, and feature history clean |
| **prototype-to-production** | you scale a prototype past 3D printing | it weighs tooling cost, breakeven volume, and lead time across molding, CNC, and casting |
| **tolerances-fits** | you specify dimensions on a mechanical part | it applies ISO 2768 and fit classes so parts assemble reliably |
| **tps** | you run production under lean principles | it provides the Jidoka and Just-in-Time pillars plus the Heijunka foundation |
| **five-s** | you organize a workspace | it standardizes sorting, setting, shining, standardizing, and sustaining |
| **waste** | you identify waste in a process | it focuses improvement on muda, mura, muri, and the 8 wastes |
| **tpm-smed** | you want equipment reliability and faster changeovers | it reduces downtime and setup time |
| **six-sigma** | you run defect-reduction projects | it applies the DMAIC cycle systematically |
| **kraljic-matrix** | you segment suppliers | it classifies suppliers by supply risk and profit impact to guide strategy |
| **jidoka-verification** | you must confirm a manufacturing or robotics behavior | it checks behavior with Given/When/Then assertions and stops on anomaly |

## When NOT to use this toolkit

- For CAD, 3D modeling, simulation, or digital twins in depth — use the 3D Graphics & CAD toolkit.
- For electrical or PCB design — use the Schematics & PCB toolkit.
- For procurement, customs, or importing goods — use the Logistics toolkit.
- For software engineering process, business modeling, or growth — use the corresponding toolkit.
