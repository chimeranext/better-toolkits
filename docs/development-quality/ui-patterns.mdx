# UI Patterns

The UI Patterns toolkit. Use it to apply reusable desktop UI/UX patterns across
any framework. Each pattern ships as a skill, a reference, and a command.

This is a **playbook**: it explains *when and why* to use each skill. For the
executable steps, open the skill itself (the runbook).

## When to use this toolkit

Use UI Patterns when you need a proven desktop interaction pattern:

- You want a collapsible ribbon-style toolbar.
- You must match a familiar desktop application layout.
- You need a consistent pattern across projects and frameworks.

It is framework-agnostic. The same pattern adapts to React, iced.rs, WinUI,
and Flutter.

## Core skills — when and why

| Skill | When to use it | Why |
| --- | --- | --- |
| **ribbon-ui** | you need a collapsible desktop toolbar or tabs pattern | it reuses a proven ribbon anatomy across frameworks |

## When NOT to use this toolkit

- For mobile-first layouts, use the Atomic Design or general UI guidance.
- For a standard toolbar, do not force a ribbon pattern.
- For business logic, this toolkit does not apply.
