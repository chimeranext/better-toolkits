# Conventional Commits

**Scope:** Commit message format `type(scope): description`; machine-readable history and changelog generation

## When to apply it

You are writing a commit message.

## Why

The standard keeps the work consistent, reviewable, and traceable across the
project. Applying it at the right time avoids rework and keeps the codebase
healthy.

## Procedure

The detailed procedure, commands, and enforcement for this standard live in
`shared/references/engineering-standards/conventional-commits.md` in the repository.
