# Copyright/License Header

**Scope:** Headers per repo LICENSE.md; not a global rule

## When to apply it

You are adding file headers or license information.

## Why

The standard keeps the work consistent, reviewable, and traceable across the
project. Applying it at the right time avoids rework and keeps the codebase
healthy.

## Procedure

The detailed procedure, commands, and enforcement for this standard live in
`shared/references/engineering-standards/copyright-license-header.md` in the repository.
