# CI Security & Standards

**Scope:** Standardized CI security gates (CodeQL/Trivy/SAST), vendorized templates, traceable evidence

## When to apply it

You are setting up CI security gates.

## Why

The standard keeps the work consistent, reviewable, and traceable across the
project. Applying it at the right time avoids rework and keeps the codebase
healthy.

## Procedure

The detailed procedure, commands, and enforcement for this standard live in
`shared/references/engineering-standards/ci-security-standards.md` in the repository.
