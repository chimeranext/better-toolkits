# Main Protections & HITL Merge Guard

**Scope:** Default branch ruleset (only named team bypass) + org-wide 2FA + pre-tool-use guard that requires interactive human approval for any bypass/admin merge. Fail-closed.

## When to apply it

You are merging into a protected branch.

## Why

The standard keeps the work consistent, reviewable, and traceable across the
project. Applying it at the right time avoids rework and keeps the codebase
healthy.

## Procedure

The detailed procedure, commands, and enforcement for this standard live in
`shared/references/engineering-standards/main-protections-hitl.md` in the repository.
