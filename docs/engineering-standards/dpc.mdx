# Dependency Caching

**Scope:** Universal pattern (lockfile + frozen install + cached store). Canonical manager per language (pnpm for Node/JS). CI caches store by lockfile hash; local uses per-user store.

## When to apply it

You are installing dependencies or setting up CI caching.

## Why

The standard keeps the work consistent, reviewable, and traceable across the
project. Applying it at the right time avoids rework and keeps the codebase
healthy.

## Procedure

The detailed procedure, commands, and enforcement for this standard live in
`shared/references/engineering-standards/dependency-caching.md` in the repository.
