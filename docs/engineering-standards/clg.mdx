# Commit Logic Groups

**Scope:** Commit intermediate work in semantic groups; each commit is self-contained and reviewable

## When to apply it

You are grouping commits into logical units.

## Why

The standard keeps the work consistent, reviewable, and traceable across the
project. Applying it at the right time avoids rework and keeps the codebase
healthy.

## Procedure

The detailed procedure, commands, and enforcement for this standard live in
`shared/references/engineering-standards/commit-logic-groups.md` in the repository.
