# Intra-File Structure

**Scope:** How one file reads top-to-bottom

## When to apply it

You are reading or writing a single file top-to-bottom.

## Why

The standard keeps the work consistent, reviewable, and traceable across the
project. Applying it at the right time avoids rework and keeps the codebase
healthy.

## Procedure

The detailed procedure, commands, and enforcement for this standard live in
`shared/references/engineering-standards/dsms-ifs-cps.md) §2` in the repository.
