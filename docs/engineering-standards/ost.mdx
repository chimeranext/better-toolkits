# OpenSpec store PR traceability

**Scope:** Tracker → change folder → one store PR → one merge

## When to apply it

You are opening an OpenSpec store pull request.

## Why

The standard keeps the work consistent, reviewable, and traceable across the
project. Applying it at the right time avoids rework and keeps the codebase
healthy.

## Procedure

The detailed procedure, commands, and enforcement for this standard live in
`shared/references/engineering-standards/openspec-store-pr-traceability.md` in the repository.
