# Pull Request Description Standards

**Scope:** PR body + reviewable size; English body prose passes ASD-STE100

## When to apply it

You are opening a pull request.

## Why

The standard keeps the work consistent, reviewable, and traceable across the
project. Applying it at the right time avoids rework and keeps the codebase
healthy.

## Procedure

The detailed procedure, commands, and enforcement for this standard live in
`shared/references/engineering-standards/prds.md` in the repository.
Prose gate: `shared/references/asd-ste100/scripts/prose_gate.py markdown`
(also enforced by `shared/hooks/prds/detect.py`).
