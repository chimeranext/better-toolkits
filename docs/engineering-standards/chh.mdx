# Checksum Hygiene

**Scope:** Setup scripts pin the VERSION and verify release assets against the release's own checksum manifest — never hardcoded sha256 constants

## When to apply it

You are verifying a release or a setup script.

## Why

The standard keeps the work consistent, reviewable, and traceable across the
project. Applying it at the right time avoids rework and keeps the codebase
healthy.

## Procedure

The detailed procedure, commands, and enforcement for this standard live in
`shared/references/engineering-standards/checksum-hygiene.md` in the repository.
