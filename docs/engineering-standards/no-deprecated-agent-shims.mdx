# No deprecated agent shims

**Scope:** Renames are clean-cut: update references and delete the old path; no "MOVED (shim)" or exec wrappers.

## When to apply it

You are renaming or moving an agent tool or command.

## Why

The standard keeps the work consistent, reviewable, and traceable across the
project. Applying it at the right time avoids rework and keeps the codebase
healthy.

## Procedure

The detailed procedure, commands, and enforcement for this standard live in
`shared/references/engineering-standards/no-deprecated-agent-shims.md` in the repository.
