# Ops Documentation Taxonomy

**Scope:** Classify every ops doc as Playbook vs Runbook vs SOP. Never mix. Route via /document-this

## When to apply it

You are about to write an ops document.

## Why

The standard keeps the work consistent, reviewable, and traceable across the
project. Applying it at the right time avoids rework and keeps the codebase
healthy.

## Procedure

The detailed procedure, commands, and enforcement for this standard live in
`shared/references/engineering-standards/ops-documentation-taxonomy.md` in the repository.
