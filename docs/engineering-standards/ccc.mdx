# Code Comment Convention

**Scope:** Meaningful non-obvious comments; no redundant "how" comments

## When to apply it

You are writing comments in code.

## Why

The standard keeps the work consistent, reviewable, and traceable across the
project. Applying it at the right time avoids rework and keeps the codebase
healthy.

## Procedure

The detailed procedure, commands, and enforcement for this standard live in
`shared/references/engineering-standards/code-comment-convention.md` in the repository.
