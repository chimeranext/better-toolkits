# Venture Studio

Macro portfolio management for venture studios and serial founders. Use it when
you operate more than one venture and need to decide legal structure, allocate
resources across ventures, and match to external acceleration programs.

Where the Startup Lifecycle toolkit works on a single venture, this toolkit works
at the **portfolio** level. It supports two operating modes, set in the local
config file:

- **Studio mode** — for systematic startup studios.
- **Founder mode** — for serial entrepreneurs with multiple personal ventures.
- **Services Hub mode** — a central Services LLC contracting bilateral MSAs with each venture LLC.

This is a **playbook**: it explains *when and why* to use each skill. For the
executable steps, open the skill itself (the runbook).

## When to use this toolkit

Use Venture Studio when the work is portfolio-level:

- You are a founder with multiple startups and must choose single-LLC vs multi-LLC plus holding.
- You operate a venture studio and must shape thesis, focus, and secret sauce.
- You are evaluating external accelerators (YC, Techstars, RevTech Labs, SOSA, Plug and Play).
- You are in LATAM and must choose a structure: Skip-CR, Delaware Tostada, Cayman Sandwich, or Delaware C-Corp.
- You manage a portfolio and must apply Three Horizons, Innovation Scorecard, Cost of Delay, or Improvement Kata.

## Core skills — when and why

### Structure and jurisdiction

| Skill | When to use it | Why |
| --- | --- | --- |
| **structure-decision** | you must choose a corporate structure | it compares Single-LLC, Multi-LLC, Cayman Sandwich, Delaware Tostada, Skip-CR, and Delaware C-Corp |
| **structure-evolution-roadmap** | you need a migration path | it gives triggers (ARR, term sheet, geography) to evolve from one structure to the next |
| **jurisdiction-matrix** (reference) | you need a quick jurisdiction reference | it covers 16 jurisdictions: LATAM 8, US 3, Offshore 3, EU 2 |
| **sweat-equity-agreement** | you are granting equity for work | it defines vesting, cliff, hours×rate conversion, and 83(b) election |
| **cap-table-per-venture** | you manage equity across multiple LLCs | it models dilution through future rounds per venture |

## When NOT to use this toolkit

- For a single venture from zero to funding — use the Startup Lifecycle toolkit.
- For legal or tax advice — this toolkit generates preparation material, not legal counsel; validate with specialized lawyers.
- For a freelancer operating as a single-member LLC — use the Digital Nomad toolkit.
- For contract and delivery workflows between a fractional CTO and a client — use the Fractional CTO toolkit.
