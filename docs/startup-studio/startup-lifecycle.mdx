# Startup Lifecycle

The complete founder journey toolkit. Use it when you are a founder who wants to
start a company from nothing and grow it to a venture-backed startup:

```
No money → Save → Form entity → Raise capital → Scale
```

The toolkit targets founders with no experience in the US ecosystem who want to
internationalize their startup, typically LATAM founders.

This is a **playbook**: it explains *when and why* to use each skill. For the
executable steps, open the skill itself (the runbook).

## When to use this toolkit

Use Startup Lifecycle when the work is the founder journey:

- You are starting from zero money and need a plan.
- You need to form a US entity (Delaware PBC, Wyoming LLC).
- You need to raise capital with SAFE notes and build a cap table.
- You need to handle vesting, co-founders, investors, or advisors.
- You need to plan corporate structure or convert an existing entity.

It is the entry-point toolkit for pre-revenue founders. For portfolio-level
decisions across multiple ventures, use the Venture Studio toolkit instead.

## Core skills — when and why

| Skill | When to use it | Why |
| --- | --- | --- |
| **bootstrap-to-offshore** | you want the complete journey in one flow | it walks you from saving, to entity formation, to raising capital |
| **entity-formation** | you are ready to create a US entity | it forms a Delaware PBC or Wyoming LLC with legal documents, BOI, and registered agent |
| **fundraising** | you need to raise money | it covers SAFE notes, equity split, cap table, demo prep, and financial modeling |
| **vesting** | you are setting up equity grants | it defines vesting schedules, cliff, acceleration, and sweat equity |
| **cofounder-matching** | you need to find or evaluate a co-founder | it uses a 6-axis framework to screen fit |
| **investor-matching** | you need to find or evaluate investors | it uses a 5-axis framework to rank fit |
| **advisor-matching** | you need to add advisors | it uses a 4-axis framework and a FAST Agreement |
| **b-corp-certification** | you want B Corp status | it walks the B Lab standards and certification process |
| **cayman-sandwich** | you need a 3-tier structure for LATAM startups | it structures a Cayman HoldCo, Delaware midco, and LATAM OpCo |
| **subsidiary-conversion** | you have a LATAM SRL to move under a holding | it converts the SRL into a wholly owned subsidiary |

## When NOT to use this toolkit

- For legal, tax, or financial advice — this toolkit is educational only and you should consult a lawyer and accountant.
- For portfolio-level decisions across multiple ventures — use the Venture Studio toolkit.
- For a freelancer staying as a single-member LLC — use the Digital Nomad toolkit.
- For contract and delivery workflows between a fractional CTO and a client — use the Fractional CTO toolkit.
