# Import Cost Breakdown (rubros) — FOB → CIF

## The 9 rubros

1. Nacionalización consolidada
2. Transporte
3. Conocimiento de embarque
4. Revisión TLC
5. Gastos de despacho
6. Examen previo
7. Bodegaje
8. Inspección pre-embarque
9. Póliza (insurance)

## FOB → CIF formula

```
CIF = FOB + transporte internacional + seguro (póliza) + aranceles + gastos
```

- **FOB** = value at origin port (factory + transport to port + export taxes).
- **CIF** = FOB + freight + insurance + import taxes (duties + fees).

## Guidance

- Use **FCA** for air freight from China (seller delivers to carrier).
- Use **FOB** for sea freight (seller loads on board).
- See `../incoterms/incoterms-2020.md` for the full responsibility split.
