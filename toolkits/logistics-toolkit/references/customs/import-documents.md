# Import Documents — Costa Rica (19 doc checklist)

## Commercial
1. Factura compraventa (commercial invoice)
2. Factura de importación (import invoice, DUA basis)

## Transport
3. Conocimiento de embarque — BL (marítimo)
4. Conocimiento de embarque — AWB (aéreo)
5. Carta porte (terrestre)

## Customs
6. DUA — declaración única aduanera (import declaration)
7. Declaración del valor aduanero

## Origin / compliance
8. Certificado de origen (per TLC, see `../trade-agreements/tlcs.md`)
9. Certificado de análisis (when product-specific)
10. INCOTERM (see `../incoterms/incoterms-2020.md`)
11. Permisos / registros sanitarios (where applicable)

## Financial
12. Póliza (insurance certificate)
13. Forma de pago (payment method evidence)
14. Licencia de importación (when regulated)

## Supporting
15. Poder / carta de representación (agency)
16. Acuerdo de compra / contrato
17. Hoja de seguridad (SDS) for chemicals
18. Documento de transporte multimodal (when used)
19. Registro de importador (importer registration)

## Cost breakdown (rubros) — see `cost-breakdown.md`
Nacionalización consolidada, transporte, conocimiento de embarque, revisión TLC, gastos
despacho, examen previo, bodegaje, inspección pre-embarque, póliza.
