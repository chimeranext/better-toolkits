# CAE Skill — Multi-Tool Reference

## Purpose

This skill provides access to computer-aided engineering (CAE) workflows — finite element analysis (FEA), computational fluid dynamics (CFD), multi-body dynamics, and simulation-driven design — across open-source and commercial tools (Ansys, COMSOL, OpenFOAM, CalculiX, FMI/FMU co-simulation) for product validation and digital twin applications.

## Capabilities

- **FEA**: Structural, thermal, and modal analysis
- **CFD**: Fluid flow, heat transfer, and turbulence modeling
- **Multi-body Dynamics**: Mechanism and motion analysis
- **Model Preparation**: Meshing, boundary conditions, material assignment
- **Results Post-processing**: Stress, strain, displacement, and flow visualization
- **Co-simulation**: FMI/FMU standard integration for coupled simulation

## Usage

This skill enables CAE workflows for agents operating across Claude Code, Cursor, and OpenCode, providing tool-agnostic guidance for simulation setup, execution, and interpretation.
