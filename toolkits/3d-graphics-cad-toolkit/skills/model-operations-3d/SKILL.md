# 3D Model Operations Skill — Multi-Tool Reference

## Purpose

This skill provides access to core 3D model operations — import, export, conversion, manipulation, and validation — across file formats (STL, OBJ, GLB/glTF, USD) and tools (Blender, OpenUSD, NVIDIA Omniverse, mesh-processing libraries) for digital twin, CAD, and visualization pipelines.

## Capabilities

- **Import**: STL, OBJ, GLB, glTF, and USD import with validation
- **Export**: Format conversion with parametric and topology control
- **Manipulation**: Transform, retopology, decimation, and repair
- **Validation**: Geometric checks, manifoldness, and unit handling
- **Optimization**: LOD generation and runtime asset optimization
- **Interoperability**: Engine-agnostic scene and mesh exchange

## Usage

This skill enables 3D model operations for agents operating across Claude Code, Cursor, and OpenCode, providing tool-agnostic guidance for geometry handling.
