# CAD Skill — Multi-Tool Reference

## Purpose

This skill provides access to computer-aided design (CAD) workflows — 2D drafting, 3D solid modeling, parametric design, and collaborative design review — across open-source and commercial tools (AutoCAD, FreeCAD, Fusion 360, SolidWorks, Rhinoceros 3D, CadCraft) for digital twin, engineering, and product development applications.

## Capabilities

- **2D Drafting**: Layer management, dimensioning, annotations, sheet layout
- **3D Modeling**: Solid modeling, surfaces, NURBS, mesh workflows
- **Parametric Design**: Constraints, feature history, reusable design parameters
- **Interoperability**: Import/export of DXF, DWG, STEP, IGES, STL, GLB, USD
- **Collaboration**: Shared workspaces and design review workflows
- **Automation**: Scriptable/API-driven design generation

## Usage

This skill enables CAD workflows for agents operating across Claude Code, Cursor, and OpenCode, providing tool-agnostic guidance for drafting, modeling, and geometry handoff.
