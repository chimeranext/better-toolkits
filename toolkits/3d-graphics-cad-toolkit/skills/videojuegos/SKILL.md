# Video Game Development Skill — Multi-Tool Reference

## Purpose

This skill provides access to video game development workflows — game design, game programming, level design, art production, and quality assurance — across engines and frameworks (Unity, Unreal Engine, Bevy, Godot, OpenUSD for asset interchange) for interactive entertainment and serious games.

## Capabilities

- **Game Design**: Core loop, mechanics, and progression design
- **Game Programming**: Gameplay, rendering, physics, and AI systems
- **Level Design**: Environment layout, pacing, and player guidance
- **Art & Animation**: Asset creation and integration pipelines
- **QA & Testing**: Build validation, playtesting, and iteration
- **Interoperability**: Engine-agnostic asset and scene exchange

## Usage

This skill enables video game development workflows for agents operating across Claude Code, Cursor, and OpenCode, providing tool-agnostic guidance for game production.
