# Digital Animation Skill — Multi-Tool Reference

## Purpose

This skill provides access to digital animation workflows — 2D and 3D animation, rigging, character animation, keyframing, and cinematic rendering — across open-source and commercial tools (Blender, Cinema 4D, Maya, Toon Boom Harmony, OpenUSD for interchange) for product visualization, simulation, and motion design.

## Capabilities

- **Keyframing**: Manual and procedural animation authoring
- **Rigging**: Skeletons, inverse kinematics, and deformation
- **Character Animation**: Acting, motion, and facial animation
- **Motion Design**: Title, logo, and UI animation
- **Rendering**: Real-time and offline render pipelines
- **Interoperability**: USD/GLB asset exchange between tools

## Usage

This skill enables animation workflows for agents operating across Claude Code, Cursor, and OpenCode, providing tool-agnostic guidance for animation production.
