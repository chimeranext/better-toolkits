# rv-ODT Schema Management Skill — Multi-Tool Reference

## Purpose

This skill provides access to Open Digital Twin Format (ODT) schema management — the rv-ODT standard for representing digital twin data interoperably across platforms and tools.

## Capabilities

- **Schema Authoring**: Structuring twin data models per the ODT specification
- **Validation**: Schema conformance checks for twin payloads
- **Mapping**: Mapping between rv-ODT and platform-specific models
- **Versioning**: Schema evolution and migration management
- **Interoperability**: Exchange of twin data across systems
- **Integration**: Binding with simulation (FMI) and agriculture (DataModel.Agrifood) standards

## Usage

This skill enables rv-ODT schema management for agents operating across Claude Code, Cursor, and OpenCode, providing tool-agnostic guidance for twin data structuring.
