# VFX Skill — Multi-Tool Reference

## Purpose

This skill provides access to Visual Effects (VFX) workflows — particle systems, simulations, compositing, and rendering — across open-source and commercial tools (Blender, Houdini, After Effects, Nuke, GPU node-based pipelines) for film, advertising, and real-time experiences.

## Capabilities

- **Particle Systems**: Emitters, forces, and collision behavior
- **Simulation**: Fluid, smoke, cloth, and destruction effects
- **Compositing**: Multi-layer image composition and color grading
- **Motion Graphics**: Animated titles and graphical overlays
- **Rendering**: Real-time and offline high-fidelity render
- **GPU Pipeline**: Node-based procedural effect authoring

## Usage

This skill enables VFX workflows for agents operating across Claude Code, Cursor, and OpenCode, providing tool-agnostic guidance for effect design and production.
