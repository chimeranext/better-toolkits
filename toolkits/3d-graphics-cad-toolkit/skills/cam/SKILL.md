# CAM Skill — Multi-Tool Reference

## Purpose

This skill provides access to computer-aided manufacturing (CAM) workflows — CNC programming, toolpath generation, additive manufacturing, and design-for-manufacturability (DFM) — across open-source and commercial tools (Fusion 360 CAM, Mastercam, FreeCAD Path, PrusaSlicer, Cura) for industrial production and prototyping.

## Capabilities

- **CNC Programming**: 2.5-axis and multi-axis toolpath generation
- **Post-processing**: Machine-specific G-code generation and validation
- **Additive Manufacturing**: Slicing, support generation, and print parameter optimization
- **DFM Analysis**: Manufacturability checks and tolerance validation
- **Toolpath Simulation**: Collision detection and material removal verification
- **Interoperability**: STEP/STL handoff to machine controllers

## Usage

This skill enables CAM workflows for agents operating across Claude Code, Cursor, and OpenCode, providing tool-agnostic guidance for manufacturing process planning and execution.
