# Bevy + Iced Integration Skill — Multi-Tool Reference

## Purpose

This skill provides access to integrating the Bevy Engine (3D rendering and simulation) with the Iced cross-platform GUI library, both built in Rust, for desktop and real-time interactive applications including digital twin studios.

## Capabilities

- **Renderer Integration**: Embedding Bevy's 3D viewport inside an Iced UI
- **UI + 3D Interop**: Bidirectional events between GUI and 3D scene
- **Entity Picking**: Selecting and manipulating 3D entities from the UI
- **Cross-platform**: Windows, macOS, Linux desktop targets
- **State Sharing**: Shared application state across UI and render systems
- **Hot Reload**: Iterative development with live scene updates

## Usage

This skill enables Bevy + Iced integration for agents operating across Claude Code, Cursor, and OpenCode, providing tool-agnostic guidance for Rust desktop rendering and UI composition.
