# Digital Twins Skill — Multi-Tool Reference

## Purpose

This skill provides access to digital twin workflows — real-time virtual representations of physical assets, systems, and processes — across platforms and standards (OpenFactory, OpenTwin, realvirtual.io rv-ODT, PTC ThingWorx, Azure Digital Twins, Siemens MindSphere, NVIDIA Omniverse/OpenUSD) for simulation, monitoring, and predictive operations.

## Capabilities

- **Twin Modeling**: Geometry and semantic asset representation
- **Data Binding**: Live telemetry and sensor data synchronization
- **Simulation**: Behavioral and physics-based twin simulation
- **Schema Management**: rv-ODT and structured twin data schemas
- **Visualization**: Real-time 3D twin rendering and monitoring
- **Interoperability**: Multi-platform twin data exchange

## Usage

This skill enables digital twin workflows for agents operating across Claude Code, Cursor, and OpenCode, providing tool-agnostic guidance for twin design, deployment, and operation.
