# Prototype-to-Production Skill — Multi-Tool Reference

## Purpose

This skill provides a decision reference for when to move from **3D printing to injection molding, CNC, or casting**: tooling cost, breakeven volume, and lead time.

## Capabilities

- **Breakeven analysis**: tooling cost ÷ per-unit delta template
- **Qualitative gates**: tolerance, surface finish, material certification, and regulatory requirements
- **Process escalation**: 3D printing → injection molding / CNC / casting decision support

## Usage

This skill enables production-escalation guidance for agents operating across Claude Code, Cursor, and OpenCode. Given a "should I injection mold this / when do I stop 3D printing" question, the agent returns a breakeven analysis template plus the qualitative gates.
