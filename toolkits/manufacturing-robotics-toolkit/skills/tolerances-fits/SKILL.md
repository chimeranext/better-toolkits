# Tolerances & Fits Skill — Multi-Tool Reference

## Purpose

This skill provides a structured reference for **tolerances, fits, and clearances**: ISO 2768 general tolerances, shaft/hole fit classes, and printed-part clearance compensation.

## Capabilities

- **ISO 2768**: general tolerances for linear and angular dimensions
- **Fit classes**: clearance, transition, and interference fits (shaft/hole)
- **Printed-part compensation**: process-specific clearance (e.g. FDM hole shrinkage)
- **Nominal clearance ranges**: guidance for press fits, slip fits, and transitions

## Usage

This skill enables tolerance/fit guidance for agents operating across Claude Code, Cursor, and OpenCode. Given a "what clearance do I need for a press fit / what tolerance should I specify" question, the agent returns the fit class, nominal clearance range, and process-specific compensation.
