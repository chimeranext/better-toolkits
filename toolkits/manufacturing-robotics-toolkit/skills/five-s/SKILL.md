# 5S Methodology Skill — Multi-Tool Reference

## Purpose

This skill provides a structured reference for the **5S methodology**: the five steps with their Japanese terms, English translations, and practical descriptions.

## Capabilities

- **Seiri (Clasificación)**: sort; remove what is not needed
- **Seiton (Orden)**: set in order; arrange for efficient access
- **Seiso (Limpieza)**: shine; clean and inspect
- **Seiketsu (Estandarización)**: standardize; maintain consistent practices
- **Shitsuke (Disciplina)**: sustain; make it a habit

## Usage

This skill enables 5S guidance for agents operating across Claude Code, Cursor, and OpenCode. Given a "what is 5S / explain the 5S methodology" question, the agent returns the 5-row table with Japanese term, English translation, and practical description.
