# Kraljic Matrix Skill — Multi-Tool Reference

## Purpose

This skill provides a structured reference for the **Kraljic portfolio matrix** for supplier categorization: four quadrants on supply-risk vs profit-impact axes, with a recommended strategy per quadrant.

## Capabilities

- **Strategic**: high supply risk, high profit impact → partnership / long-term contracts
- **Leverage**: low supply risk, high profit impact → competitive bidding / leverage
- **Bottleneck**: high supply risk, low profit impact → secure supply / dual sourcing
- **Non-critical**: low supply risk, low profit impact → efficient processing / streamline

## Usage

This skill enables Kraljic guidance for agents operating across Claude Code, Cursor, and OpenCode. Given a "what is the Kraljic matrix / how do I categorize suppliers" question, the agent returns the four quadrants with axes and recommended strategy.

## References (APA)

- Kraljic, P. (1983). *Purchasing Must Become Supply Management*. Harvard Business Review, 61(5), 109–117.
