# 3D Modeling Workflow Skill — Multi-Tool Reference

## Purpose

This skill provides a structured reference for **parametric 3D modeling**: part vs assembly structure, parametric sketches, constraints, and feature history hygiene.

## Capabilities

- **Part vs assembly**: decompose the model into parts and assemblies with clear ownership
- **Parametric sketches**: fully-constrained sketches with named dimensions
- **Constraints**: geometric and dimensional constraints applied intentionally
- **Feature history**: ordered, editable feature history with stable naming/versioning

## Usage

This skill enables 3D modeling guidance for agents operating across Claude Code, Cursor, and OpenCode. Given a "how do I model this part / parametric vs direct modeling" question, the agent returns the part/assembly tree, sketch constraint strategy, feature ordering rules, and naming/versioning conventions.
