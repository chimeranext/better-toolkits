# Six Sigma Skill — Multi-Tool Reference

## Purpose

This skill provides a structured reference for **Six Sigma** including the DMAIC cycle and certification paths.

## Capabilities

- **DMAIC**: Define, Measure, Analyze, Improve, Control; data-driven defect reduction; 3.4 defects per million target
- **Certification paths**: SCOR, SCOR-DS, APICS CSCP with descriptions and exam requirements

## Usage

This skill enables Six Sigma guidance for agents operating across Claude Code, Cursor, and OpenCode. Given a "what is Six Sigma / explain DMAIC / what certifications" question, the agent returns the DMAIC cycle and certification options.

- Pyzdek, T., & Keller, P. (2018). *The Six Sigma Handbook* (5th ed.). McGraw-Hill.
