# Waste Elimination Skill — Multi-Tool Reference

## Purpose

This skill provides a structured reference for the **types of waste in Lean**: muda / mura / muri and the 8 wastes.

## Capabilities

- **muda**: non-value-adding activity
- **mura**: unevenness / inconsistency
- **muri**: overburden / unreasonableness
- **8 wastes**: defects, overproduction, waiting, non-utilized talent, transportation, inventory, motion, extra-processing

## Usage

This skill enables waste-elimination guidance for agents operating across Claude Code, Cursor, and OpenCode. Given a "types of waste in Lean / muda mura muri / 8 wastes" question, the agent returns the definitions and the 8-waste list.
