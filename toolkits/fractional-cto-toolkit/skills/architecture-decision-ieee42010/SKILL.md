# architecture-decision-ieee42010

Read and follow [`references/architecture-decision-ieee42010/protocol.md`](../../references/architecture-decision-ieee42010/protocol.md) (protocol SSOT). The record is MADR 4.0.0. - Heading order stays the MADR order. The filled client file writes those headings in the engagement working language.
