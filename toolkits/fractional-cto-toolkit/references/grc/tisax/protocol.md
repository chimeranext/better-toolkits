# Skill `tisax` — protocol SSOT

## Purpose

Prepare an organization for a **TISAX** (Trusted Information Security
Assessment Exchange) assessment — the automotive industry's information
security assessment standard operated by the ENX Association using the VDA
ISA catalog. Suppliers demonstrate security to OEMs by sharing TISAX
assessment results within the exchange.

Grounded in the CTO-role references (Splunk, Devox; Sushegaad GRC as benchmark
only).

## When to use

- A client is a supplier or service provider to automotive OEMs requesting
  TISAX.
- A client must meet a TISAX label requirement in a supply contract.
- A client wants a single assessment reused across OEM relationships.

## Method

1. **Scope the assessment**: define the label scope (which locations,
   departments, and information domains — e.g., prototype protection, data
   protection, information security) and confirm the OEM's requirement.
2. **Select the assessment level**: TISAX assessment levels — AL1
   (self-assessment), AL2 (onsite assessment, the common default), and AL3
   (onsite with more extensive sampling for high-security needs). Choose per
   the label requirements.
3. **Map the VDA ISA catalog**: complete the self-assessment against the ISA
   control catalog (information security management incl. ISO 27001-aligned
   controls, organization, personnel, physical, IT/cloud, data protection,
   and prototype protection where relevant).
4. **Gap analysis**: identify controls below target; build a remediation plan.
5. **Implement and evidence**: close gaps and prepare evidence before the
   assessment.
6. **Book and run the assessment**: choose an accredited TISAX audit
   provider; the results are published in the ENX exchange for OEMs to view.
7. **Maintain**: TISAX labels are valid for three years; keep the ISMS
   current and handle change events.

## Artifact

A TISAX readiness pack: scope decision, level selection, VDA ISA
self-assessment with scoring, gap plan, and evidence index.

## Contract

- The assessment is run by an accredited audit provider; this skill prepares
   and supports, it does not replace the audit.
- The scope matches the actual label request from the OEM.
- Vendor-neutral and client-neutral.
- Handover: on engagement end, transfer to the Chief Compliance Officer (CCO)
  — scope, level, gaps, evidence.
- Verify against the current VDA ISA version and ENX rules.
