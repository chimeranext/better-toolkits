# Análisis de riesgos · {{org_or_process}}

Organizational risk/opportunity register. Schema derived from common ISO
9001:2015 + ISO 31000:2018 analysis worksheets (field model only — original
prose). For software **project** risk management plans use ISO/IEC/IEEE 16085
via `/software-project-management-plan`.

## Context

| Dimension | Notes |
| --- | --- |
| External | Legal, economic, social, technological, competition |
| Internal | Capability, knowledge, infrastructure, ethics |
| Interested parties | Requirements that, if unmet, impact the organization |
| Processes | Activities that can produce nonconforming outputs |
| Products & services | Customer/spec/norm noncompliance |
| OH&S hazards | Ineffective operational controls → injury/illness |
| Environmental aspects | Ineffective controls → pollution |

See also `fuentes-y-agentes.md`.
