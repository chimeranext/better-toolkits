# Fuentes y agentes de riesgo

Lookup lists for `analisis-riesgos-iso31000.md` (original prose; field model
aligned to common 9001/31000 worksheets).

## Fuentes

| Fuente | Ejemplos |
| --- | --- |
| Contexto externo | Variables legales, económicas, sociales, tecnológicas, competencia |
| Contexto interno | Capacidad comercial/tecnológica, conocimiento, infraestructura, ética |
| Partes interesadas | Requisitos no abordados que impactan a la organización |
| Procesos | Actividades mal ejecutadas → salidas no conformes |
| Productos y servicios | Incumplimiento de requisitos del cliente, especificaciones o normas |
| Peligros SST | Controles operacionales ineficaces → accidentes/enfermedades |
| Aspectos ambientales | Controles ineficaces → contaminación |

## Agentes (ejemplos SST / operativos)

| Categoría | Origen | Ejemplos | Lesiones / efectos típicos |
| --- | --- | --- | --- |
| Mecánico | Ambiente mecánico de trabajo | Máquinas, herramientas, objetos | Caídas, golpes, cortes, aplastamiento |
| Físico | Ambiente físico | Ruido, temperatura, humedad, radiaciones | Trastornos fisiológicos/psicológicos |
| Químico | Sustancias y productos | Polvos, humos, gases, vapores | Respiratorio, dermatosis |
| Laboral | Ritmos y organización del trabajo | Esfuerzo, postura, movimiento | Musculares, tendinitis, bursitis |

Extend categories for cyber, privacy, financial, and supply-chain risks as the
engagement requires — do not force SST categories onto software-only contexts.
