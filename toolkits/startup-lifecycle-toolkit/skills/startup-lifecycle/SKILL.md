# startup-lifecycle

Complete guide to the founder journey from zero money to raising venture capital.

**FREE** — This toolkit is completely free. No entrance fee.

## Audience

Founders with no experience in the US ecosystem who want to internationalize their startup.
Typically LATAM founders (Costa Rica, Mexico, Colombia, etc.).

## The Journey

```
No money → Save → Form entity → Raise capital → Scale
```

## Available Commands

| Command | What it does |
|---------|--------------|
| `/startup-lifecycle:bootstrap-to-offshore` | Complete journey: save → form entity → raise capital |
| `/startup-lifecycle:entity-formation` | Form Delaware PBC, Wyoming LLC + legal documents + BOI + registered agent |
| `/startup-lifecycle:fundraising` | SAFE notes, equity split, cap table, demo prep, financial modeling |
| `/startup-lifecycle:vesting` | Vesting schedules, cliff, acceleration, sweat equity |
| `/startup-lifecycle:cofounder-matching` | Find and evaluate co-founders (6-axis framework) |
| `/startup-lifecycle:investor-matching` | Find and evaluate investors (5-axis framework) |
| `/startup-lifecycle:advisor-matching` | Find and evaluate advisors (4-axis framework + FAST Agreement) |
| `/startup-lifecycle:b-corp-certification` | B Lab Standards, certification |
| `/startup-lifecycle:cayman-sandwich` | 3-tier structure for LATAM startups |
| `/startup-lifecycle:subsidiary-conversion` | Convert SRL to wholly owned subsidiary |
