# Protocol: cayman-sandwich

Guide to the Cayman Sandwich structure for LATAM startups raising venture capital.

## What is the Cayman Sandwich?

3-tier structure:

```
Cayman Islands TopCo (holding company)
    └── Delaware LLC (pass-through buffer)
        └── Local OpCo (local operations)
```

## Advantages

| Advantage | Description |
|-----------|-------------|
| **Tax treatment** | Avoids 21% US corporate tax on exits |
| **Predictable law** | Cayman corporate law mirrors Delaware |
| **Flexibility** | Easier to flip from Cayman to Delaware than vice versa |
| **Investor friendly** | VCs are familiar with Cayman TopCo |

## Disadvantages

| Disadvantage | Description |
|--------------|-------------|
| **Cost** | 3 entities in 3 jurisdictions = higher costs |
| **Complexity** | Need advisors in multiple jurisdictions |
| **US buyers** | If your buyer is US-based, doesn't avoid 21% tax |
| **European investors** | Some avoid Cayman |

## When to use it?

- Yes: Significant institutional funding, exit NOT US-based, operations outside US
- No: Expected exit is US-based buyer, operations in US, local/European investors

## Flips (LATAM → Cayman/Delaware)

1. Shareholders of the LATAM entity exchange their shares for shares in the new entity
2. The LATAM entity becomes a wholly owned subsidiary
3. Key issues: tax, timing, cap table, governance, jurisdiction
