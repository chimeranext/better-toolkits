# Player Psychology Skill — Multi-Tool Reference

## Purpose

This skill provides access to **player psychology** — motivation, engagement, cognitive load, and behavioral design — for video game development across engines (Unity, Unreal Engine, Bevy, Godot).

## Capabilities

- **Motivation**: intrinsic vs extrinsic rewards, self-determination theory
- **Engagement**: flow state, challenge-skill balance, retention loops
- **Cognitive Load**: information design, learnability, onboarding
- **Behavioral Design**: habit formation, loss aversion, variable reward schedules
- **User Research**: playtesting, telemetry interpretation, player feedback

## Usage

This skill enables player psychology guidance for agents operating across Claude Code, Cursor, and OpenCode. Given a "why do players churn / improve onboarding / design a retention loop" question, the agent returns structured psychology-based recommendations.

## References (APA)

- Koster, R. (2013). *A Theory of Fun for Game Design* (2nd ed.). O'Reilly Media.
- Engelstein, G. (2020). *Achievement Relocked: Loss Aversion and Game Design.* MIT Press.
- Anthropy, A. (2012). *Rise of the Videogame Zinesters.* Seven Stories Press.
