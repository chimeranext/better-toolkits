# Game Design Mechanics Skill — Multi-Tool Reference

## Purpose

This skill provides access to **game design mechanics** — core loop design, mechanism design, progression systems, reward schedules, and strategic balance — for video game development across engines (Unity, Unreal Engine, Bevy, Godot, OpenUSD).

## Capabilities

- **Mechanism Design**: core loop design, progression systems, reward schedules
- **Strategic Balance**: multi-agent coordination, strategic depth, fairness
- **Game Theory Mechanics**: payoff matrices, Nash equilibria, zero-sum vs cooperative design
- **Player Agency**: decision space, meaningful choices, emergent gameplay
- **Iterative Design**: prototyping, playtesting, and feedback loops

## Usage

This skill enables game design mechanics guidance for agents operating across Claude Code, Cursor, and OpenCode. Given a "design the core loop / balance these mechanics / model this strategic interaction" question, the agent returns structured game design and game theory guidance.
