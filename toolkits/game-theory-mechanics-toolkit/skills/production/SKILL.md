# Game Production Process Skill — Multi-Tool Reference

## Purpose

This skill provides access to **game production process** — project management, scope control, milestones, build pipelines, and shipping — for video game development across engines (Unity, Unreal Engine, Bevy, Godot) and workflows.

## Capabilities

- **Project Management**: milestones, sprinting, vertical slices, scope control
- **Production Pipelines**: asset pipelines, build systems, version control (Perforce/Git)
- **Team Process**: playtesting cadence, iteration reviews, producer workflows
- **Shipping**: release readiness, QA, certification, platform submission
- **Post-launch**: live ops, patches, content updates

## Usage

This skill enables game production guidance for agents operating across Claude Code, Cursor, and OpenCode. Given a "plan this milestone / scope this vertical slice / prepare for release" question, the agent returns structured production guidance.
