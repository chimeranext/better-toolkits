# Changelog

All notable changes to this toolkit will be documented in this file.

## [1.0.0] - 2026-10-19

### Added

- Initial release of `digital-nomad-toolkit`
- Skill principal: `digital-nomad`
- 5 commands: `entity-formation`, `tax-compliance`, `banking`, `msa-b2b`, `visa-options`
- 5 reference protocols
- Guide for freelancers and digital nomads operating as US Single-Member LLC
- Remote banking options (Mercury, Relay, Wise)
- Non-resident tax compliance guide
- International billing (MSA B2B) guide
- Visa options for digital nomads (B-1, E-2, H-1B, ESTA)
