# BIM Skill — Multi-Tool Reference

## Purpose

This skill provides access to Building Information Modeling (BIM) workflows — intelligent 3D modeling, clash detection, 4D/5D scheduling, and facility management — across open and commercial tools (Revit, ArchiCAD, BlenderBIM/IfcOpenShell, IFC standard) for architecture, engineering, and construction (AEC).

## Capabilities

- **Intelligent Modeling**: Building elements with parametric properties
- **IFC Interoperability**: OpenBIM data exchange via Industry Foundation Classes
- **Clash Detection**: Spatial conflict analysis between building systems
- **4D/5D**: Schedule and cost linking to the model
- **Facility Management**: Asset data handoff for operations and maintenance
- **Digital Twin Feed**: Geometry and semantics export for twin visualization

## Usage

This skill enables BIM workflows for agents operating across Claude Code, Cursor, and OpenCode, providing tool-agnostic guidance for model authoring and data exchange.
