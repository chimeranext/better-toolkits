# TPM & SMED Skill — Multi-Tool Reference

## Purpose

This skill provides a structured reference for **Total Productive Maintenance (TPM)** and **Single-Minute Exchange of Die (SMED)**.

## Capabilities

- **TPM**: integrated maintenance where equipment stops automatically if an anomaly is detected; zero-unplanned-downtime goal
- **SMED**: reduce setup/changeover times; adapt machinery quickly; reduce lot sizes

## Usage

This skill enables TPM/SMED guidance for agents operating across Claude Code, Cursor, and OpenCode. Given a "what is TPM / what is SMED / quick changeover" question, the agent returns the principles and goals.

## References (APA)

- Nakajima, S. (1988). *Introduction to TPM: Total Productive Maintenance*. Productivity Press.
- Shingo, S. (1985). *A Revolution in Manufacturing: The SMED System*. Productivity Press.
