# Logistics / Supply Chain Skill — Multi-Tool Reference

## Purpose

This skill provides the supply-chain / import domain for startups importing goods into Costa Rica (or any LATAM market): procurement (P2P, SRM, Kraljic), customs regimes, import documentation, INCOTERMS 2020, free trade agreements, and inventory management.

## Capabilities

- **Procurement**: 10-step Procure-to-Pay flow, SRM, Kraljic matrix (Strategic/Leverage/Bottleneck/Non-critical)
- **Customs regimes**: CAUCA (Ley 8360), Ley 7575, zona primaria/secundaria, regimes taxonomy
- **Import documents**: 19-document checklist grouped by function (commercial/transport/customs/origin/financial)
- **Cost breakdown**: 9 rubros + FOB→CIF formula
- **INCOTERMS 2020**: 11 codes, responsibility matrix, FOB vs CIF, FCA guidance
- **Trade agreements**: Costa Rica TLCs + certificado de origen
- **Inventory**: WMS vs ERP, forecasting, MPS, SCOR/APICS certifications

## Usage

This skill enables supply-chain guidance for agents operating across Claude Code, Cursor, and OpenCode. Given a "what is P2P / how do I categorize suppliers / what documents do I need to import / FOB vs CIF / what TLCs apply" question, the agent returns the structured reference (SSOT under `references/`).
