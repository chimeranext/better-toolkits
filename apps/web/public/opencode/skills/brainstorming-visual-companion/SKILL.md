# Brainstorming / Visual Companion

For multi-venture portfolio decisions (e.g., which app catalog next,
bi-directional wrapper design, accelerator matching), use a visual
brainstorming artifact before committing:

- **Divergent phase**: list all alternatives (single-action vs. multi-subcommand wrapper; freemium vs. free trial; Services Hub vs. Full Studio).
- **Convergent phase**: score by `impact × ease` or `cost-of-delay / duration` (CD3 framework).
- **Parking lot**: document rejected alternatives with rationale (prevents revisiting without new evidence).
- **Evidence link**: reference protocol artifacts (`catalog-evidence.md`, `postmortem-*.md`) so the decision is traceable.

This complements `cost-of-delay-cd3` (prioritization) and `premortem`
(blind-spot exposure) within the toolkit pipeline.
